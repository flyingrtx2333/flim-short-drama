# 镜头状态与实际切点验收

在相邻镜头、反打、续拍或局部重做时使用。沿用项目现有文档，不另建平行权威。方法借鉴 drama-skills 的起终边界、最小连续性锁与改写回归；用户已有制作授权继续有效。

## 制作前：同一场面的一套事实

记录入口、固定空间锚点、人物距锚点的位置、身体朝向、头眼目标、持物与动作阶段。左右必须标明是人物自身还是画面；反打可以改变屏幕方向，不能改变世界位置。未知尺寸记为估计，参考图不能证明的关系不称已验证。

不随剧情改变的身份、服装、空间关系写成简短连续性锁，在相关可复制提示词里保留相同事实；走动、停步、门开合、灯亮等变化另写状态，避免把人物锁死。用正向可见关系说明动作，不在每次失败后永久追加全局禁令。

每镜至少记录：

| 字段 | 内容 |
| --- | --- |
| 职责 | 本镜给观众的唯一主要变化或新信息 |
| 起点→动作→终点 | 人物、手脚、道具、视线及环境状态；交互对象的运动/变化与人物动作相容，转换在画内发生或有明确叙事省略依据 |
| 摄影机 | 机位、轴线侧、触发、路径和落点；正面角度不等于人物转身 |
| 时间与声音 | 生成时长、计划成片时长、动作和反应预算、声音事件；快运镜与人物正常速度分开 |
| 参考用途 | 实际文件及版本，分别约束身份、场景几何、起始状态或道具；仅有提示词不算已有图 |

冻结首帧只表现起点，尾帧只表现终点。上一镜终点与下一镜起点不一致时修订动作或覆盖，不能靠“电影感反打”解释。连续续拍优先使用实际合格衔接帧；供应商明确支持参考视频时才同时提供上一段实际视频，不虚构字段或以计划图冒充实际尾帧。独立生成的反打图需重新核对同一空间锚点和人物距离。

需要动作或机位无缝续接时，下一段首帧必须来自上一段实际采用区间的最后一帧，按剪辑出点前最后帧提取，而非素材的未采用末尾。规划汇总标明“首帧待上一分镜视频实际采用结尾帧生成”和来源镜号；先生成并审阅上一段、确定采用出点，再提取实体帧，以它设计下一段尾帧并执行首尾帧过渡。记录源视频、零起始帧号、时间、路径和依赖状态。待生成占位可以审阅动作计划，不能提交生成；源出点变化时重新提帧并更新下游输入。声音驱动没有严格端点控制时，先生成必要过渡，再从过渡实际结尾续拍，按实际接点验收。

## 参考图阶段：同一局部场景先成立

同一建筑、同一场所名称、相似材质或来自同一摄影组，都不能证明是同一通道或同一段货架。为同场镜头指定一份当前空间依据，核对已有照片能定位的局部关系：货架层数与高度、通道宽度、柱子与架列的相对位置、门墙标记、灯具排列、目标道具和人物距离。按透视解释预期变化，不能只锁“蓝色货架、混凝土、黄金”等类别词。单图也可能在生成新机位时改变结构，图像与视频两阶段都复核。

同时核对摄影机看到的人体表面是否与身体朝向相容。固定前方墙面仍在同一朝向远景，却把前进人物从后背直接改成正面胸口，可能是人物被转身而非摄影机换位；相同背景不能证明反打成立。真实侧机位可用同一局部架列及墙面方向交代前进；人物为触物侧向目标和转回入口是不同动作，应按实际身体、目标与摄影机关系判定。

参考图先并排比较共享可见锚点，最好同时有一个主视角作位置基准。反打的后墙不同可以合理，但人物邻接的同一架列、支撑结构和尺度仍应兼容；所有背景强行相同也会错。缺少可定位的反向照片时优先收紧覆盖到已有空间可证实的区域或寻找对应原照，不随意换另一条通道；生成未知反面须按视觉参考中的授权与标记要求处理。

已见货架层数、柱架关系、通道尺度等矛盾，判为地理失败，退出当前采用并修参考，不只写“精确机位未验证”后继续作为同一场面交付。仅缺证据时保留未验证项并改选能成立的覆盖；道具插入镜或声音桥不能替已知换场景开脱。新镜头只改善真实感也要回归此前的空间锁，不能为自然光、随拍风格或更好看重建场景。

## 生成后：验收实际采用的边界

检查对象是实际采用区间，而非提示词、任务状态或整段素材最后一帧。按三个层面记录采用决定；局部合格不能替代整场合格：

| 层面 | 检查与依据 |
| --- | --- |
| 素材内 | 查看实际采用动作的开始、过程和结果，覆盖其间的接触、遮挡及快运动；比较形状、文字、持物和交互状态，不能只挑好看的首尾帧 |
| 切点间 | 对有连续性义务的切点保存两侧源文件、源时间/帧号、配对截图及身体/视线、道具、世界位置、动作阶段结论；比较切前后动作，不只比较背景相似度 |
| 场面整体 | 回到该场面的叙事变化：原因、反应、行动和结果是否有对应证据，关键关系是否读清；声音或转场不能替代缺失的画内行动，片段都有运动不代表场面有因果 |

主体位移用其相对固定锚点的变化判断，避免把摄影机运动、景别变化、局部震动当成另一个主体已完成移动或交互。文字和物体结构检查整个被采用区间的稳定性，不由一帧正确推断后续无变形。短转场及快动作按实际帧率密集检查；自然速度、声音表演、口型和整体节奏仍需正常速度音画核实，抽帧和信号分析不代替这些判断。

- 已确认动作、结构、起终状态或世界位置矛盾：标记失败区间并退出采用，修输入、覆盖或切点后再验；不以模糊、闪白、插入镜遮盖错误，也不把失败降级为“未验证”。
- 缺少关键证据：记为待补证据，不能填通过或据此推进依赖它的镜头；保留允许的叙事省略，不因缺少无关细节拒绝素材。
- 满足本镜职责且实际切点兼容：记录合格区间，才能进入该时间线；后续改动仍需检查受影响的关系。
- 风格、镜头偏好：按创作者方向选择，不能仅因偏离示例判失败。
- 技术完整：只证明解码、时长、音轨等技术事实；任务完成、1倍时基与漂亮单帧均不证明连续性或自然速度。

工具无法核实的方面明确记为未验证，不因此忽略已经能看到的矛盾。确需交付进度时准确标成未验收工作样片；已知失败素材仅作明确诊断用途，不混入声称修好或合格的预览。状态与证据写回现有素材清单或检查记录，无需建立额外审批流程。

修订后比较原有职责、起终状态、动作/反应、资产、声音和用户要求是否保留，并复查替换镜头两侧。一个项目的停留秒数和失败经验不写成所有短剧的固定配额。镜长由信息读取、表演和声音事件决定，缩短特写优先调整入出点，不整体加速人物或BGM。
