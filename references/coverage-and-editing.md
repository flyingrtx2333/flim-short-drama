# 先规划剪辑，再拍镜头覆盖

多镜头视频制作、补拍或节奏修订时读取。用户选择长镜头时按其路线制作，不强制增加镜头或素材数量。

## 三个不同对象

- **场面动作**：同一时空里实际发生一次的行动、情绪与信息变化。
- **拍摄覆盖／生成素材**：从不同景别、机位或表演版本记录相同动作区间，为剪辑提供选择。
- **成片镜头**：从素材里采用的具体入出点。同一素材可以分段采用；同一动作可被多个机位拍到，但成片不因此重复发生。

每个连续机位用一张起始图，和整场只生成一条视频是两回事。需要正面、背身与手部覆盖时，分别准备同场景、兼容动作阶段的参考图与视频。不同参考图不是默认按顺序插值的帧，一张图也不证明未见反面的地理结构。

## 从注意力倒推覆盖

先写观众应理解的变化，例如进入未知空间→听见灯响→认出目标→判断数量→靠近确认→触摸。给拟采用镜头写切入原因、新信息和切出触发，再列所需机位。没有注意力或表演变化的相邻镜，即使改了裁切也不自动成立。

人物试探、威胁或关系反转是场面核心时，先明确刺激→判断变化→采取行动，再让机位承载各转折。参考片对标、关键问答一直放在双人中景或人物反应难读时，按 [参考片、镜头与声音](film-language-and-reference-study.md) 选择听者反应、过肩／反打及关键细节，不按一句台词一镜机械交叉。剧本改了警告或知情顺序时，核对旧镜序的决断原因是否仍成立。

通常用可读的空间／动作主镜头作为位置基准，再按需要补人物正面或侧面反应、视线对象、关键手部／道具细节。主镜头可拍完整关键行动供选择，但不要求每个机位重复生成整场，也不要求成片保留主镜头全长。其他机位只覆盖剪辑真正需要的局部行动。

在现有计划内为每条素材简记：

| 字段 | 决策用途 |
| --- | --- |
| 场面与动作区间 | 各机位记录同一次行动的哪些重叠阶段 |
| 机位／景别与职责 | 空间、人物表演或细节；摄影机在哪侧，不让人物为镜头转身 |
| 关键转折的可见依据 | 哪项刺激引起哪项判断／行动；对应反应是否在采用景别里读得清 |
| 起始与结束状态 | 支撑脚／重心、身体和视线、手、物体及距固定锚点的位置 |
| 生成时长与计划采用时长 | 生成用于完整行动及必要前后余量，采用长度由节拍决定 |
| 可切点与备选覆盖 | 眼神转移、迈步、伸手、接触、反应；切不了时用哪条合格素材 |
| 输入与地理结论 | 实际参考文件、控制范围、共享锚点、缺口与冲突 |

重叠覆盖提供选择，不代表重复播放。手部特写包含接触前、接触和接触后；接回中景时手已在兼容阶段，不能又伸一次。步态匹配比较实际支撑脚、前进位置与手臂阶段，不能按两个素材各自的第几秒直接拼。

## 生成组织

1. 按 `continuity-contract.md` 核对各机位的同一局部空间；先做受影响的代表图，地理冲突先修图，不能先生成视频再用特写遮住。
2. 先验证整场最关键的动作关系，尤其多主体交互、接触、位置变化或事件触发的反应；取得可读的空间与状态依据后，再扩展依赖它的特写和反打。主镜头、动作重叠覆盖及画外声音均可按叙事选用，不强迫所有场面拍成连续全景。默认每条覆盖素材只完成一条清楚的动作与机位路线。已验证且耦合有益的短组合可原生生成多镜头，例如反应→甩镜→目标；记录实际内部切点，独立审阅并保留有效区间。不能把整场多景别全交给一次生成后失去剪辑选择。
3. 从分镜配置起按自然快语速对白、动作与必要反应收紧预估，选择较短整段生成时长，只加明确需要的少量剪辑余量。可并行的对白和动作不重复累加；短句、扫描和反应镜不默认留长段。不要先生成长视频再用后期倍速补救，工具的整数时长不是成片长度。费用按总生成秒数估算，不把真实导演拍多条当作无限批量授权。
4. 按 `continuity-contract.md` 先标出合格区间、动作完成帧和失败/待补证据区间，再选择镜序。每条采用区间都要有本镜职责及可验证的变化/信息依据；不按提交顺序或文件编号剪，也不先拼完再让用户找内容问题。

## 剪辑决定

需要在地点／时代建立镜交代背景时，按 [scene-info-graphics.md](scene-info-graphics.md) 规划左下角逐行场景信息。先核对该镜的有效内容、文字阅读时间与注意力交棒，再落实独立文字层；不能靠延长空等或遮挡关键动作满足排字。

先把必要动作剪通，再按注意力与情绪调整节奏。空间读完可切人物，视线转移可切对象，手开始动作可切接触细节，结果出现后可回人物反应。需要读持续表演或新揭示时延长；无变化的站立、行走或背部素材不能因为生成了就用完。

短反应／细节交替后用较长中景或全景落稳，是可选结构，不是每隔一两秒必须切镜。短切应改变注意对象或观察距离；角度、景别近似且表演不推进的重复背身，裁切一次仍会拖沓。不要全局快进，也不要用相似景别的突兀裁切冒充新覆盖。

同时判断短切与画内运动的叠加：移动中景刚定位人物，又切背身、再切移动近景，会反复迫使观众重新找脸和空间；源素材原速、各切点单独成立也不证明整段易读。用户反馈“乱、太快、晕”时，优先删去无必要的来回覆盖，保留一个能读完整行动的主镜头，细节只在关键动作处插入并接回连续阶段；不能单纯把碎片各延长一点。快速揭示后安排稳定观察的机会，镜长仍由实际表演决定，不新增通用秒数门槛。由同一素材裁取细节时保留跨切点的连续现场声。

先做粗剪判断缺什么，再只补关键反应、接触或连续性所缺的素材并复查两侧。旧的静止反应不能冒充后续边走边看的反应，裁切全景不能冒充新机位；能看清且连贯的局部裁切可用于细节覆盖，但如实记录。

现场声／对白可在有来源时跨画面剪辑，以环境底、呼吸、脚步及必要J/L-cut保持场面连续。连续声音不证明画面是同一空间，也不能掩盖变形或人物瞬移。BGM保持原速，不要求每刀都对音乐重拍。

## 停顿与有效时长

规划时区分生成余量与成片节拍：写出动作完成、首字、末字、反应变化和下一触发的位置，以及希望保留的停顿作用。对白镜的提示词明确何时开口、自然说完所需时间、句后做什么；不用“平静”“电影感”代替发声预算，也不要求人物为了填满生成秒数一直站着。

粗剪后逐段检查：进入/停步后是否已经无事可看；特写切入后是否只是等开口；句后是否只重复同一表情；对话接棒是否无故变成轮流等待。对可疑区间记录源入出点、实际推进及保留或删除理由。停顿可以服务思考、迟疑、读取、威胁或悬念，但画面/声音必须能读到这项作用；“营造氛围”不能解释任意长度的无变化停留。对已被用户指出无意义的停顿先取舍，不只增大音乐或在同一画面上推近。

动作或信息完成后及时交棒；对白前后余量按实际呼吸、口型、反应决定，不统一留几秒，也不删光所有停顿。先缩短空等，再判断句内语速是否仍拖沓；必要字音、动作完成与可读反应不靠全局快进解决。由全景接近景时，把两条素材各自的开口前余量合并评估，避免停步等待一次、切特写又等待一次。

删掉空等后不机械补齐原总时长，不把多出的时间转移到另一静止镜头。用户把节奏作为本次修订目标时，按有效内容交付并说明时长变化；仍明确要求固定长度时，用真实叙事内容满足或报告素材缺口。重新建立全部下游时间：原生音画共同裁切，字幕随实际发声移动，音乐保持自然节拍重新编排，环境跨切点连续，事件音效按新动作帧对齐。不能直接截断总混音后让音乐产生跳拍。

## 整段观看验收

试片与成片交付前必须执行 [storyboard-design-review.md](storyboard-design-review.md) 的“交付前整场审查与内部返工”；以实际时间线而非素材编号判断可读性，审查失败先修，不将用户首次观看当内部质检。

除源切点配对外，检查注意力序列与停顿清单：何时给新信息，哪里重复内容，长时间背身／静物是否仍有揭示或表演，关键行动是否读到。正常速度检查开口等待、接话、动作交棒和句后拖尾，不能只核对总秒数。稀疏抽帧辅助定位，短甩镜用实际帧率密集查看，整体节奏及声音仍需要正常速度的音画观看。未实时观看就保留限制，不能凭解码、1倍时基或多个文件相接宣布节奏合格。

## 来源与适配

- [Adobe：主镜头与覆盖](https://www.adobe.com/in/creativecloud/video/production/cinematography/camera-shots-and-angles/master-shot.html)：主镜头提供动作与空间基准，也介绍可替代多机位覆盖的复杂主镜头。

- [电影艺术与科学学院：Film Editing指南](https://www.oscars.org/sites/oscars/files/complet_film_editing_activities_guide.pdf)：从多机位、多次表演中选择素材，以镜序和长度组织注意、时空与节奏。

上述来源说明拍摄与剪辑原则；单图生成、付费任务组织及地理验证是当前AI流程的适配，不是来源规定的固定拍法。
