# MV 工坊中的短剧项目

仅在配置了 MV 工坊项目约定的工作区中适用（下文以 `<MV_WORKSPACE>` 指代工作区根目录）。其他工作区不自动套用本文件的目录与角色约定。先读取当前 `AGENTS.md`，以其最新内容及用户指令为准。

- 新短剧默认放在 `电影短剧/<作品名>/`；续作沿用原位置。创建具体作品时再建目录，不在技能安装时生成空项目。
- 每个具体短剧项目内保存 `角色参考/`、`场景参考/` 的实体文件及来源/版本清单；需要全局原图时将原文件复制入项目，不用符号链接或共享哈希库替代。用户要求角色三视图时保存所有指定主角的三视图，同时保留已有角色的唯一优先原身份，不因重做视角而换脸。项目引用不得只依赖全局目录或聊天附件。
- 复用现有角色、场景、素材整理与任务记录能力，但剧情片按台词和叙事时间线组织，不依赖歌曲原音。
- “长郡校服富江”目前是**新 MV** 的默认女主，不自动扩大为全部短剧默认角色。短剧用户指定使用该角色时读取 `角色参考/长郡校服富江/README.md`；已有项目沿用其当前角色。
- 使用该女主时以 README 最新指定的 `用户指定严格角色参考-三视图.png` 为唯一优先身份及服装参考；单幅视频身份图可以使用其直接裁切的 `用户指定严格角色参考-全身单幅.png`。实际传入参考，不混用历史推演图，不镜像身份图。
- 写实分镜按视觉参考的“现场随拍参考流程”优先普通现场照片，使用当前镜头原照并匹配现场光线、曝光、透视、清晰度与噪点；人物置入不自动转成精修写真。用户明确选择专业电影摄影或其他视觉风格时尊重选择。
- 查找人物与场景素材从工作区或当前项目的 `角色参考/`、`场景参考/` 及对应 README 开始，不再从 `素材库/共享素材/` 查找或引用。修改另存版本，保留原始素材和历史版本。
- 保留剧本、有效生成素材、角色与场景参考、台词音频、计划、任务记录、字幕及历版成片。清理按项目约定保存记录；复制时使用 `.rsync-exclude` 排除运行环境、缓存与中间产物，完整复制项目参考实体文件并核对引用。旧参考链接先改为内容一致的实体文件。
