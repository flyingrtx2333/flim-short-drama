# 剧本、分镜和连续性记录

在进入素材制作或继续旧项目时使用。沿用已有格式，不为短任务强制创建全部文件。新制作项目应有可复用的剧本、计划、参考图、声音、任务记录、字幕和历版成片；只有写剧本的任务不需要空素材目录。

## 最小记录

计划可以使用 JSON、表格或 Markdown，记录足以重建剪辑的信息：

| 对象 | 记录内容 |
| --- | --- |
| 项目 | 作品及集数、目标时长和画幅、视觉风格、制作范围、当前版本与批准范围 |
| 角色 | 稳定编号、当前唯一优先身份参考、服装版本、当前音色参考实体路径及来源/优先版本、当前关系及已知信息 |
| 场景 | 稳定编号、原始参考和来源、时间与光线、空间布局、人物出入口 |
| 台词 | 编号、说话者、完整文本、声音模式、原生视频/音轨来源及版本、实际时长、停顿、是否画外音 |
| 镜头 | 编号、场景、起止景别、摄影机路径与落点、人物及动作起止、视线与移动方向、切镜动机、参考图、动作及运镜完成的验收依据、原生对白区间（用户选音频驱动时才记录驱动区间） |
| 时间线 | 成片起止、生成时长、源素材入出点、声音跨切点关系、可用覆盖及余量 |
| 快速运镜/转场 | 起点与落点、世界空间关系、人物站位依据、实际末帧续拍引用、运动方向、加速/模糊/减速段、成片停留时长、变速与后期处理、音乐/音效落点 |
| 任务与检查 | 工作流、任务 ID、输入引用（含音色参考版本与说话者映射）、参数、状态、成本依据、检查方法、问题与替换关系 |

不要记录密钥或完整 base64 媒体载荷。批准记录绑定实际参考图和计划版本，避免旧确认被误用到新镜头。

## 可执行分镜

设计、修订及提交前执行 [分镜合理性自检与调优](storyboard-design-review.md)：先审整场人物目标与调度，再审各镜的动作、反应、空间、节奏和切点。发现问题在现有镜头记录内修正，不为审查另造重复表格；按实际结果和反馈更新依赖镜头。

### 叙事变化与生成约束

对影响剧情理解的动作或揭示，在现有镜头记录里简记“触发→人物察觉/反应→行动→结果”。它可以跨镜、由画外声音触发或按既定拍法省略，不要求每镜套完整链条；需要观众读懂的关键变化必须有对应证据。

| 要点 | 制作决定 |
| --- | --- |
| 变化主体与状态 | 哪个人、物体或环境从什么状态变为什么状态，靠什么动作/交互完成；摄影机运动单独记录 |
| 呈现与证据 | 哪段画面、声音或可理解的省略交代变化；既定拍法要求画内发生的行动不能仅靠音效证明 |
| 保留与允许变化 | 身份、材质、结构等保持；位置、姿态、持物、开合等按动作发展。参考图应表现所选起点，不预先完成结果 |
| 小样与采用依据 | 优先试最影响整场成立、最容易产生交互错误的动作；记录实际完成区间和失败区间，再扩展依赖它的覆盖 |

提交前把这些记录与**实际会传入的图和最终提示词**对照，尤其复查复用模板中的“保持原状”类约束。人物反应的原因是否成立，环境是否发生所需变化，图里是否已经到了终态，文字是否又锁住了要运动的主体？矛盾先修输入，不送出后再用快切补救。动作过多或关系无法读清时简化覆盖或拆分，不扩大剧情。

验收可用反事实提问辅助：去掉声音或镜头运动，画内动作还发生了吗；保留声音，人物的反应仍能对应既定事件吗？答案按当前拍法判断，不能因此强迫画外事件现身、要求静物运动，或取消作者有意的省略与风格化。

- 每镜只安排在所选时长内能够完成的主要动作与表演变化。超过当前工作流长度时合理拆镜，给反应与剪辑留覆盖；不能为了整数生成时长拉伸台词。
- 记录镜头开始和结束时人物的动作状态，例如“右手已抓住门把手，门未开”与“门开至一半，视线转向走廊”。后续镜头从兼容状态继续。
- 反打保持人物屏幕位置、视线和空间轴线。需要越轴时用能解释空间关系的中性镜头或可见运动过渡，不无意镜像角色。
- 人物转身、坐下、走过门、递交物品时，记录道具在哪只手、人物朝向和动作阶段；检查反打后物品是否消失、换手或重复交接。
- 双人对话可以安排一人说话与另一人反应的覆盖；关键表演需要同框时保留同框，不一律拆成独角戏。多人口型及声音映射不确定时先核实工作流能力或做范围内的小样。
- 审阅参考图时检查身份、服装、手和道具、空间、嘴部可见性。即将说话的特写不要默认安排遮嘴或极侧脸。

## 场面与镜头的连续性

多镜头制作按 [coverage-and-editing.md](coverage-and-editing.md) 区分场面行动、生成覆盖与成片镜头。计划写拟剪节拍和所需覆盖、机位间的动作重叠、候选切点、生成长度与采用长度；不把视频任务编号直接当作剪辑时间线。

先按连续时空与人物目标划分场面，再决定场面内的镜头；不要把逐句台词或参考图编号直接当作剪辑点。一个场面可按信息变化切换全景、人物正面、反打和关键道具特写；也可在适合时用平移/横移/弧线运动/跟拍连续切换注意对象。用户要求多个分镜时提供实际覆盖，不以同一地点或生成时长上限为由压成单一背后跟拍。摄影机动是现场透视、遮挡及景别变化，不是把静态单人肖像依次推近。

为连续镜头记录初始站位、道具落点、可行的摄影机路线、说话顺序、移动触发和结束站位。运镜将露出的关键房间区域与反转道具也要提供实际参考；不要只给初始肖像、再用画外限制指望新视角自动正确。相邻镜头记录三项衔接：身体/道具上一动作到下一动作；人物从哪里走到哪里；上一句导致什么下一步。指示“带上东西”必须让观众知道什么东西，并看见准备或带走；转场到电梯或另一办公室要有出发/到达依据。

用户要求一镜到底时先测试当前工作流支持的完整连续覆盖。长度不足可压缩对白和无效停顿，或在同一现场用实际末帧续拍；续拍衔接需检查摄影机位置、动作阶段、声画时序，不能把拼接的独立肖像或跳变称为一镜到底。不得为回避多人口型直接退回每句一张图。只有经过验证的工具限制才说明具体缺口。

运镜围绕信息和情绪变化设计景别与关注点。例如发现反转可先留脸部特写捕捉停顿与震惊，再实机拉开/横移交代人物和目标的相对位置，最后顺视线落到道具特写。保留脸部发声可见的覆盖，必要时以动作匹配切衔接不同实机运动；不要把“一镜到底”当成所有场面的硬要求，也不要为丰富而堆无法执行的快速转向。逐段验收起始景别、移动触发、中间信息和落点，不以“有横移”替代整条运镜要求。

人物拜、看、指向的对象必须在其前方或视线所及处。先用空间依据确定人物、供台/目标和摄影机位置；关键道具的参考是外形依据，不是让物体在运动中变形或把人物朝向翻转。默认先寻找实拍场景及关键道具原照，核实摄影出处和适用覆盖，实际传入图像工具并记录来源；用户指定地点时核实对应现场。AI演绎画面与现场原照分开标记，不以凭空生成的近似地点冒充实拍。

核对位置不能只看画面左右或是否同框：要看房间内的前后距离、门槛内外、身体与视线朝向，以及目标的正面是否朝向人物。望风者与搬运者应保留可读的门外/门内关系；拜神者站在供台正前方，不能把“面前有神像”当成已经面对神像正面。

反打参考共用同一房间布局。机位换边可改变物体的屏幕位置，不能为保持构图把门窗或供台挪到另一面墙；普通对话的特写要沿真实对手视线拍摄。大幅连续绕拍不能稳定保持关系时，用有动机的反打交代位置，再接实际移动的道具近景。

## 分镜汇总

先按 [storyboard-rendering.md](storyboard-rendering.md) 选择每段生成模式并记录接点；必须首尾帧的段落标橙框、模式文字、配对编号及实际首尾双图。使用 `../scripts/render_storyboard.py` 从项目 JSON 清单渲染，按内容扩展画布。参考模式不得冒称首尾帧控制，当前工作流不支持所需模式时在汇总阶段指出，不留到提交后补救。

默认交付一张覆盖用户指定完整制作区间的汇总图片。每镜展示实际参考图，并清晰排印编号、完整台词（非对白写“无对白／旁白／环境声”等）、动作、时间和声音来源；按从左到右、从上到下的时间顺序排列。镜头较多或文字较长时增大画布，保持原尺寸放大后可读，不只交付缺少完整台词与动作的缩略概览。分页详图可作为补充，不能代替完整单图；用户明确选择分页时以其要求为准。图像工具负责镜头画面，汇总使用确定性排版，检查全部卡片文字的溢出、截断和顺序；默认直接展示完整单图并提供原尺寸文件。

## 修订影响

台词、角色声音或语速变化通常需要重生成对应原生视频；用户选外部音频时同时更新音频和对白镜头；位置及顺序变化要核实动作衔接与声画区间。原生模式镜头更换场景时保持角色声线方向、重生成对应音画；用户已选外部声音时才保留仍适用的录音，口型不匹配时重做视频。记录废弃版本与替换关系，不用改名掩盖素材实际内容，也不覆盖有效历史成片。

修订按改变的事实传播：动作起终、物体状态、人物位置、道具版本或光线变化后，查找引用该事实的反应、特写、反打和声音桥，并重新核对实际入出点。不只检查新片段本身，也不自动重做整集；兼容素材保留，冲突素材退出采用。用户反馈是发现入口，不把审查范围限于用户指出的一个画面；同一已知原因影响的采用区间一起检查。
