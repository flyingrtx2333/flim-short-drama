# 分镜合理性自检与调优

设计或修订分镜、准备生成、选择实际素材、粗剪及交付试片/成片前必读。沿用项目已有记录，仅保存发现的问题、修订决定和证据；不新增逐镜审批或为每镜写重复检查清单。

## 先审整场，再审单镜

明确本场人物目标、权力关系、当前位置及观众应理解的变化，通读完整镜序。按下列维度找具体矛盾；没有矛盾不为丰富画面强加动作或切镜。

| 检查 | 调优决定 |
| --- | --- |
| 动作的动机与职责 | 起身、离桌、绕行、递物、转身改变了什么？只为凑时长或换景别的移动删掉，用人物表演或合理机位承载。权力关系影响调度，但不规定所有统治者必须坐着；明确的剧本动作与用户选择优先。 |
| 刺激与人物反应 | 被追、受伤、被扫描、听到裁决时，人物具体察觉什么，眼、脸、手或身体怎样回应？反应能否在所选景别看清？必要时切近景。锁定身份、位置不等于锁死表情和动作。 |
| 物理与动作可拍性 | 重心、惯性、支撑、接触和恢复是否可信？复杂跌倒/碰撞优先短接触特写、合适覆盖或明确动作省略，不强迫模型全景展示高难度连续翻转。省略前后状态必须兼容，不能用音效或快切掩盖已知穿模与瞬移。 |
| 世界观与整场视觉 | 建立镜与后续实景是否表达同一个世界状态、时间和光线逻辑？不能出现文字称废墟、画面却像繁荣绿城的矛盾。检查实际镜头中的额外人物、前景身体、身份、道具和标志；不因主角正确而忽略背景错误。跨地点或统治中心的有意反差按剧情判断，不强行统一所有场景。 |
| 空间与视线 | 按同一场景检查人物高度、前后距离、桌椅/门槛阻隔、轴线、视线对象及方向。坐姿对象变为站姿或反之，所有反打、过肩和反应镜重新检查。不能只看画面左右。 |
| 信息、节奏与声音 | 默认快语速作用于所有角色；威严、温柔不自动意味着缓慢。分镜预估和整段生成秒数是否过长？按自然快语速、动作与必要反应收紧，只留少量必要余量；不默认用后期倍速补救。首字、末字、接话、反应停顿各有什么作用？删空等、重复动作和重复信息，不为原定总时长补静止段。配乐不能代替表演推进。 |
| 切镜的动机与兼容状态 | 每刀将注意力交给什么新信息？近景看清关键接触/判断后接回兼容阶段，不能又跌倒、追上或起身一次。严格续拍按实际采用末帧执行；硬切和时间省略明确记录，不冒称无缝。 |
| 字幕、说话与沉默 | 计划文字与素材内嵌文字分开检查，去掉多余或重复字幕。无对白反应镜既不能有额外台词，也不能保留说话口型；只静音不算修复。讲话者、已选声线和可见嘴部对应。 |

选择在当前故事与授权内最简洁且能读懂的方案。每个关键镜简记“叙事作用／人物起终状态／可见反应或接触／可切点与有效时长／实际检查证据”，复用既有字段即可。参考图、最终提示词和人物状态不一致时先修输入；位置锁、动效、语速、声线及动作时间预算也须一致。

## 用实际结果调优

1. 优先验证最难的交互或动作，再扩展依赖镜头；不等完整试片交给用户才首次找明显矛盾。
2. 对照实际动作及对白，标记合格入出点、失败区间和缺证据项。按问题选择删余量、换覆盖、修参考或重生成；不能只增加提示词禁令。
3. 同类问题连续出现时改变拍法或约束：复杂总景改有接触证据的近景/省略，呆板反应解除姿态冻结并给刺激，空等改发声预算或有效剪辑。避免只换种子反复提交。准备修改先完成自检，在现有用户授权内执行，不扩展到无关镜头或未经授权的生产。
4. 用户指出问题后，检查同一原因影响的所有已采用覆盖。改站位传播到反打/过肩/结尾，改语速传播到字幕/切点/配乐，删除台词同时检查说话画面。兼容区间保留，冲突区间退出采用；再检查新段及两侧真实切点。
5. 在现有项目修订记录留下“实际问题→原因→方案改变→采用证据→未验收项”。用户明确提出通用偏好时更新技能；一次项目的具体坐姿、机位或倍速留在该项目，不自动变成所有作品的默认。


## 实际素材的修复边界

- “不加字幕”“不说话”“只有一个人”等提示词不是输出证据。分别检查原始生成视频、裁切后的无后期文字画面及最终合成，辨认模型烧录字与计划字幕；检查旁听者和反应镜的口型及额外声音。相关声音/字幕问题按 [dialogue-and-editing.md](dialogue-and-editing.md) 修复。
- 裁切可以移除边缘生成字或误入人物，但先检查实际出现范围、整段变化及裁切后的构图。不得裁掉关键动作、身份特征、接触证据或场景定位来掩盖错误；保持合理画幅和人物比例。需要这些信息才能看懂时改参考或重生成，不把裁切当通用补救。
- 无对白反应镜起始参考本身若像正在讲话，先改为适合该情绪的嘴部状态，再生成可见情绪变化；仅写“禁止说话”不足。采用区间避开计划外说话口型，并清理额外声音；过短的有效区间若读不到剧情反应，应换覆盖或重做，不能默认冻结静帧延长。
- 分开记录计划生成秒数、服务实际输出时长和最终采用区间。实际比请求时长长时按完整动作/字音取舍，不用后期倍速补救，也不误报请求秒数为实际时长。镜头内部切换、表演和音效哪些由模型生成，哪些由剪辑改动，交付说明按实际来源表述。

抽帧、ASR、时长及解码各有用途，但不能证明实时动作自然、语速听感或口型合格。有正常速度音画观看能力时检查整场；没有时标明限制。已知错误不能改写成“待验收”继续采用，修复必须在真实输出中发生。


## 交付前整场审查与内部返工

用户要求“一遍过”：用户看到的第一版应已通过内部合理性审查，而不是模型只生成一次，也不是未经检查就交出试片让用户逐镜找错。保留既有授权和分辨率确认规则；本审查不新增用户审批。修复在当前范围内主动执行，不据此无限重试、改故事或扩展付费范围。

### 三处审查不能互相替代

- **分镜配置前**：先审整场人物的目标、知情顺序、刺激→判断→行动→后果，确认每个关键变化有可读覆盖。给每刀明确切入/切出原因、相邻起终状态和内容时间预算；不能按台词句数、生成编号或整数秒数自动拆镜。快语速减少无效等待，不压缩威胁、动作接触和空间建立到无法理解。
- **素材进入时间线前**：按实际运动标出动作开始、接触、停住、首字/末字及内部切镜，核对角色、服装、鞋、道具结构、标志、场景锚点、手脚支撑和视线。可疑突切、接触和闪帧逐帧看，不靠稀疏缩略图。严格续拍使用实际采用末帧；相似类别或提示词相同不证明身份与几何连续。关键缺口不能填“通过”。
- **粗剪与最终合成后**：检查实际时间线上的整场注意力、动作阶段、声音交棒和反转落点，再正常速度听看从开头到结尾；局部重剪后复查修改段及两侧。技术解码、原速时基、ASR和单帧只提供各自证据，不代表整体节奏、动作自然度、声线或口型验收。

### 应主动退回的具体情形

| 实际发现 | 采用决定与修复 |
| --- | --- |
| 模型内部特写只闪几帧，又立刻回近似宽景 | 默认作为意外闪切定位；剧情若无明确闪现动机就退出。选择完整可读覆盖；需要保留原生首字时用有来源的J/L-cut，不直接截掉音节。禁止把短暂闪帧描述为已完成特写表演。 |
| 建立镜或关键威胁刚出现就切走，观众尚无法定位或理解 | 按该镜的信息量和真实表演重选出点/覆盖；有动作但不够可读仍需修复。不能为排除失败尾段，把残余短片强行当完成的动作；不规定所有作品通用的最低秒数。 |
| 手触地后直接变成不兼容姿态，或抓握前后接触对象/支撑突然改变 | 补可信动作覆盖或改拍法。允许有意省略，但省略必须前后兼容、结果可读；声音、快速切镜或插入近景不能掩盖已知瞬移、穿模和错误后果。 |
| 去掉模型错误后，关键动作或信息也随之消失 | 标为缺覆盖并补素材。错误后的状态不能因截走错误过程就自动合格；若只采用失败前的独立有效动作，后续须从其实际状态重新建立并审查，不返回错误结果冒充连续完成。 |
| 各段分别合格，但连接后重复跌倒、抬手、奔跑、识别或等待 | 用重叠动作阶段选切点，保留一次行动及必要反应；删无信息的来回跳切，不靠整体倍速或给碎片各加一点时长。 |
| 裁字幕迫使构图失去接触、身份、空间或表演重点 | 修输入/覆盖或重做；不得由技术裁切反过来主导叙事机位。原素材→处理后的无后期字镜头→最终成片逐层检查，按字幕实际最高/动态位置确定范围，不只检查底边。 |
| 完整台词存在，但说话者、情绪、快慢、接话或沉默反应不成立 | 核对同源音画及当前固定声线；字幕正确、音色参考已传入、转写词汇接近均不能替代声音与表演。实际没有打断/重叠就不宣称实现了该动作；不靠后期字幕重叠伪造。 |
| 音轨逐片段拼接，环境底、首尾音节、配乐落点或反应声未连贯 | 按新画面重新组织连续现场环境、必要J/L-cut、对白/音乐层和事件落点。逐切点回听；音画同源剪辑优先，不能用盖音乐或静音掩盖讲话口型。 |

### 问题必须改变决定

沿用项目已有记录，简记“时间码/源帧→实际问题→重剪或补覆盖→真实修复证据→剩余未验证项”。每个明确失败都必须有退出采用或经实际证据闭环的修复结果；不得仅在长记录中写出缺陷，却继续交付并称已修好。无法完成当前范围的修复时明确素材缺口，不把局部修复版当整片合格。

原始生成失败、剪辑失败和工具无法验证分别处理。先尽可能利用可用听看/分析能力；确实没有可靠正常速度音画验证能力时，交付前明确缺失的验收项，只能标为诊断/未验收工作样片，不能宣称“一遍过”“声线已统一”“节奏合格”。这不降低对已可见问题的退回要求，也不默认把质检责任交给用户。

同类问题再次出现，先改变参考用途、动作负载、机位覆盖或时间预算，再在已有授权内局部重做；不重复堆叠禁令或只换种子。复用已通过部分，避免把内部返工变成无关镜头的无限批量生产。
