# 分镜模式选择与通用汇总图

## 先选衔接，再选工作流

逐一判断相邻镜头：有意硬切、同一条连续素材内部状态、还是需要生成连续过渡。跨场景的空间旅行、形状匹配变换、推入/拉出指定构图、须落到下一镜明确画面的过渡，采用真正的首尾帧模式；普通叙事切镜不必全部插值。首尾帧控制起止画面，不保证中间的物理路径与动作天然正确。

对每条必须首尾帧的生成段记录 `mode=first_last`、配对编号、首/尾实体图片、衔接理由、计划时长、运镜及工作流。它是一个从首帧到尾帧的生成任务，不是分别生成两张参考图的视频再硬拼。尾帧与下一段首帧需要无缝延续时复用同一实体图片；续拍优先用经审阅的上段实际采用末帧，并记录其源视频及帧号，更新下段输入。若由原设计尾帧改为实片末帧，技术衔接修复遵循已有授权；实质改变构图、场景或角色则更新受影响分镜。

AutoDL 当前首尾帧入口为 `minimax_h3_lightx2v`，按已保存接口定义实际提交 `first_frame`、`last_frame`。`u24`、`v5` 的 `ref_image_*` 是参考，不是这两个字段。用户指定 u24 时，在分镜汇总中就说明首尾帧段的能力冲突，展示所需例外工作流或待解决状态；不得悄悄把橙框段降级成多图参考或硬切。由用户明确要求某段改首尾帧时，按授权执行该段；按已保存参数与费用执行，检查实际输入及生成边界；不另查实时参数或计费。

## 汇总必须可见的标记

- **依赖上一段实际末帧的续拍段**：规划时不要独立生成其首帧。图内明确写“首帧待上一分镜视频实际采用结尾帧生成”，标明来源镜号及切点选择；展示待生成占位框和已设计尾帧，状态为“依赖未就绪／不可提交”。上一段生成并选定剪辑出点后，提取出点前最后一个实际采用帧（不是整条素材最后帧），保存源视频、零起始帧号、时间及实体PNG，再补入首帧并更新汇总。依赖链按顺序制作，不并行提交互相依赖的镜头。
- 需要连续落地、姿态变化或到达指定机位时，从该实际末帧生成尾帧分镜，再用真正首尾帧任务完成中间动作。音频驱动不支持严格首尾帧时，先完成必要的无对白过渡，再以其经审阅实际结尾作为对白参考；不得用独立新姿态硬切冒充修复。一般叙事硬切无需强制继承末帧。

- **橙色粗边框 `#FF9C36`：必须首尾帧**。卡片同时显示“首尾帧”、配对编号、首帧与尾帧两幅图、工作流与衔接理由；不能仅靠颜色，也不能仅在旁边文档说明。
- 灰框为参考、音频参考或文生段，写明对应模式。相邻卡片若也是首尾帧任务，各自标橙框；普通镜头只作为别段尾帧来源时不用冒称自己也必须首尾帧。
- 图内保留完整编号、时间、动作、完整台词／歌词或纯音乐段落、声音、运镜；不得为了固定卡片高度截字。整张图包含图例，按时间顺序排列。
- 场景背景介绍在对应画面内部显示真实排字预览，不能只写成卡片说明。使用 `scene_info` 自动叠字，默认全部行显示后的状态；卡片列出逐行时点。阶段预览另存以补充顺序，预览图不冒称已经烧录进视频。
- 没有合格尾帧时先补图，不能输出省略尾图的“可生产”橙框汇总。草案须明确待补状态，不能据其提交视频。

## 共享渲染器

统一使用本技能的 `scripts/render_storyboard.py`，电影短片与 MV 共用同一实现。项目保存 JSON 清单和输出图片，不再每个项目重写排版脚本。需要新布局时修改并验证通用脚本；用户特别要求的例外布局另行记录。

依赖 Python 3 + Pillow；字体默认探测 macOS 黑体和 Linux Noto CJK，可用 `--font` 指定。文件路径相对清单所在目录解析，也接受绝对路径。画面完整等比放入，不裁掉端点；长中文、歌词及文件名自动换行，卡片与总画布按内容增高。渲染失败先修清单或字体，不绕过端点检查。

```sh
python /path/to/film-short-drama/scripts/render_storyboard.py /project/storyboard.json --output /project/分镜汇总-v2.png --columns 3
```

清单最小示例（实际图片须存在）：

```json
{
  "title": "项目分镜 v2",
  "subtitle": "完整时间线 · 生成方式已标注",
  "notes": ["本图为制作计划，非生成结果"],
  "shots": [
    {
      "id": "T01",
      "title": "从太空落到荒原",
      "time": "0—3 秒",
      "mode": "first_last",
      "pair": "T01：宇宙 → 荒原",
      "first_frame": "参考/宇宙.png",
      "last_frame": "参考/荒原.png",
      "workflow": "minimax_h3_lightx2v",
      "join": "连续下落转场，尾帧复用下一段首图",
      "action": "日出后向地表推进，落在黑石碑全景",
      "dialogue": "无对白",
      "sound": "宏伟铜管延续",
      "camera": "大远景推进至荒原全景"
    },
    {
      "id": "S02",
      "title": "角色反应",
      "time": "3—6 秒",
      "mode": "audio_reference",
      "image": "参考/角色.png",
      "workflow": "当前已核实的音频参考工作流",
      "action": "角色转头后捧腹大笑",
      "dialogue": "无对白",
      "sound": "已确认原笑声",

```

字段：每镜必填 `id/title/time/mode/action/sound` 以及 `dialogue` 或 `lyrics`（MV 完整歌词／纯音乐段落）。`reference/audio_reference` 必填 `image`；`first_last` 必填 `first_frame/last_frame/pair/join`；`text` 不要求图片。`workflow/camera/note` 为补充字段。`--columns` 支持1—6，`--card-width` 默认1080、最小600。

### 场景文字预览字段

需要背景介绍的镜头添加 `scene_info`。渲染器读取干净的 `image`，在汇总图内确定性叠字，源文件不变。`frames` 默认 `["image"]`；首尾帧模式按实际需要显式指定 `["first_frame", "last_frame"]` 或其中一个。尺寸以 `design_height` 为设计基准，随图片高度缩放；`anchor` 为内容图归一化左上文字锚点。过界报错，不静默缩小文字。

```json
"scene_info": {
  "style": "tech",
  "font": "字体/当前中文字体.ttf",
  "design_height": 480,
  "anchor": [0.065, 0.77],
  "tracking": 1.0,
  "line_gap": 10,
  "accent": "#78DAF5",
  "lines": [
    {"text": "白宫", "size": 28, "color": "#EFF8FF", "enter": 0.3, "reveal": 0.2},
    {"text": "DeepSeek统治中枢", "size": 22, "color": "#A8DBEC", "enter": 1.0, "reveal": 0.2}
  ],
  "preview_time": 1.4,
  "preview_label": "全部显示状态；后期叠字计划，未写入原片",
  "exit": 3.0,
  "exit_fade": 0.2
}
```

`enter/reveal/preview_time/exit` 是该镜内部秒数，不是全片时间；出口与阅读余量按实际镜长调整。`font` 相对清单解析，省略时使用汇总图中文字体。`style=cinematic` 为无硬框的文字与柔和阴影，`plain` 为简洁文字底，`tech` 增加科技风角线（仅在用户选择此视觉时使用）；具体题材用实际字体和配置适配，不把科技风强加给其他短剧。可导入脚本中的 `render_scene_info(image, spec, base, fallback_font, preview_time=...)` 保存阶段预览，共用排字实现；这只是静帧预览，最终逐行动画需独立合成和回看。

仅规划占位例外：可暂缺 `first_frame`，改填 `first_frame_dependency={"shot":"S02","status":"pending","selection":"上一分镜视频实际采用结尾帧，剪辑出点确定后提取"}`；尾帧仍须存在。参考／音频段暂缺 `image` 时可同理用 `image_dependency`。渲染器显示待生成框与“不可提交”，不把占位框当输入图片。解析完成后填真实路径，将依赖状态改为 `resolved`，记录 `source_video/source_frame/source_time`；重新渲染后才能提交依赖段。缺图且没有明确pending依赖仍报错。此规划例外不允许用虚构图片、设计尾帧或失败素材冒充上一段实片末帧。

提交前将清单模式与任务载荷逐条比对；提交后查看真正采用的首/尾边界、运动方向、动作阶段和声音衔接。橙框只表示制作要求，不表示已完成或连续性已通过。
